Dual Consumption Channels

发布后，两种方式即可接入

开放 API 与 Workbench 对话共享同一套执行引擎，行为完全一致，用量统一计入同一份账单。

开放 API

标准 REST 接口，支持同步与 SSE 流式返回，自动生成 OpenAPI 文档。

POST /api/v1/agents/rsch-01/streamMsg
Authorization: Bearer sk-********
{
  "message": "帮我调研三家竞品定价"
}

← 200 event-stream
data: {"reply":"正在检索…"}

Workbench 对话

无需集成即可直接使用，内置调试模式，逐步展示工具调用与子 Agent 调度过程。

Build Process

三步构建一个可用的 Agent

不需要理解编排逻辑，勾选能力、确认配置、发布即可，执行顺序交给 Agent 自己决定。

01 / SELECT

挑选能力

从市场检索或让平台按任务描述智能推荐一组 Tool / Skill / Agent 组合。

02 / CONFIGURE

配置策略

设定记忆策略、权限范围与递归深度上限，中间件 Hook 均可按需启用。

03 / PUBLISH

发布调用

一键发布，自动生成 API 文档与 Workbench 入口，即刻可被集成或对话使用。
